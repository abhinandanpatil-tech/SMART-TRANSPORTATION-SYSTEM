# 🚌 Smart College Transportation System

A comprehensive real-time GPS bus tracking system for college campuses built with native Android (Kotlin) and Firebase backend.

## 📱 What This System Does

## Features

### User Features (Students)
- **Secure Login**: Email and password authentication
- **Route Search**: Find buses by selecting source and destination
- **Bus List**: View available buses with schedules
- **Live Tracking**: Real-time GPS tracking on Google Maps

### Admin Features
- **Secure Admin Login**: Privileged access for administrators
- **Route Management**: Full CRUD operations for bus routes
- **User Management**: Manage student accounts and roles
- **Driver Safety Monitoring**: 
  - Overspeeding alerts (>40 km/h)
  - Route deviation alerts (>100m off-route)
  - Prolonged stoppage alerts (>15 minutes at non-designated stops)

## Technology Stack

### Frontend
- **Platform**: Native Android
- **Language**: Kotlin
- **Maps**: Google Maps Android SDK
- **UI**: Material Design Components

### Backend
- **Authentication**: Firebase Authentication
- **Database**: 
  - Cloud Firestore (static data)
  - Firebase Realtime Database (live GPS data)
- **Serverless**: Firebase Cloud Functions
- **Security**: Firestore Security Rules

## Architecture

### Database Schema

#### Cloud Firestore Collections:
- `users`: User accounts with roles (admin/user)
- `routes`: Bus routes with schedules
- `route_geofences`: Geofenced paths for safety monitoring
- `operation_alerts`: Safety alerts generated by Cloud Functions
- `bus_stops`: Designated bus stop locations

#### Firebase Realtime Database:
- `live_bus_locations/{busId}`: Real-time GPS coordinates
- `bus_location_history/{busId}`: Historical location data

### Safety Monitoring System

The system uses Firebase Cloud Functions to automatically monitor bus operations:

1. **Overspeeding Detection**: Triggers when speed exceeds 40 km/h
2. **Route Deviation**: Uses geofencing to detect when buses deviate >100m from designated routes
3. **Prolonged Stoppage**: Alerts when buses stop >15 minutes at non-designated locations

## Setup Instructions

### Prerequisites
- Android Studio Arctic Fox or later
- Firebase project with Firestore, Realtime Database, and Functions enabled
- Google Maps API key

### Installation

1. **Clone the repository**
   ```bash
   git clone <repository-url>
   cd SmartCollegeTransport
   ```

2. **Firebase Setup**
   - Create a new Firebase project
   - Enable Authentication, Firestore, Realtime Database, and Functions
   - Download `google-services.json` and place in `app/` directory
   - Update the configuration in `app/google-services.json`

3. **Google Maps Setup**
   - Get a Google Maps API key
   - Add the key to `app/src/main/AndroidManifest.xml`:
     ```xml
     <meta-data
         android:name="com.google.android.geo.API_KEY"
         android:value="YOUR_GOOGLE_MAPS_API_KEY" />
     ```

4. **Deploy Cloud Functions**
   ```bash
   cd functions
   npm install
   npm run deploy
   ```

5. **Deploy Firestore Rules**
   ```bash
   firebase deploy --only firestore:rules
   firebase deploy --only firestore:indexes
   ```

6. **Build and Run**
   - Open the project in Android Studio
   - Build and run on device/emulator

### Sample Data

Import the sample data from `sample_data.json` to get started with test routes and users.

## Usage

### For Students
1. Login with student credentials
2. Select source and destination from dropdowns
3. View available buses and their schedules
4. Tap on a bus to track it live on the map

### For Administrators
1. Login with admin credentials
2. Access the admin dashboard
3. Manage routes (add, edit, delete)
4. Monitor safety alerts in real-time
5. View alert locations on the integrated map

## Security

- Firebase Authentication for secure login
- Role-based access control (admin/user)
- Firestore security rules prevent unauthorized access
- Cloud Functions run with admin privileges for safety monitoring
